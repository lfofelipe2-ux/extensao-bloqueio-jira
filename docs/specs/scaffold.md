# Spec: scaffold

Slice owner: scaffold. Other slices (options, service worker, dialog, spike, jira-client) build on this and must not need to edit these files.

## Goal
Give the repo a loadable Manifest V3 skeleton plus the shared storage and auth modules every other slice imports.

## Deliverables
- `manifest.json` (MV3): service worker `src/background/service-worker.js` (module), `action` with the grey icon, `options_ui` -> `src/options/options.html`, permissions `storage`, `alarms`, `optional_host_permissions: ["https://*/*"]`.
- `icons/{grey,green,orange}-{16,32,48,128}.png`, generated by `tools/generate-icons.mjs` (no dependencies).
- `src/lib/storage.js`
- `src/lib/auth.js`
- `src/background/service-worker.js`: stub, replaced by the service-worker slice.
- `README.md`: load-unpacked steps, plus the warning that the token is stored unencrypted in `chrome.storage.local`.
- `package.json`: only for `npm test` (`node --test`), `"type": "module"`, no dependencies.
- `tests/storage.test.js`, `tests/auth.test.js` with an in-memory `chrome.storage` mock.

## Contract

### storage.js
Keys in `chrome.storage.local`:
- `settings`: `{jiraUrl, email, apiToken, scopedToken, cloudId, boardId, columnId, primaryStatusId, secondaryStatusId, pollSeconds}`
- `runtime`: `{state, issueKey, summary, statusName, tooltip, offline, reason}`

Exports:
- `DEFAULT_SETTINGS` (strings empty, `scopedToken: false`, `pollSeconds: 60`), `DEFAULT_RUNTIME` (`state: "unknown"`, `offline: false`, rest empty), `MIN_POLL_SECONDS = 30`.
- `getSettings()`: stored values merged over defaults, `pollSeconds` normalised.
- `setSettings(patch)`: merges the patch into the stored settings, clamps `pollSeconds` to >= 30 (invalid -> 60), returns the saved object.
- `getRuntime()`, `setRuntime(patch)`: same merge semantics, no clamping.
- `isConfigured(settings)`: true when URL, email, token, boardId, columnId, primaryStatusId and secondaryStatusId are set and the two statuses differ; scoped tokens also need `cloudId`.

### auth.js
- `getBaseUrl()`: Jira URL without trailing slashes; for scoped tokens `https://api.atlassian.com/ex/jira/{cloudId}`. Throws if the needed field is missing.
- `getAuthHeaders()`: `{Authorization: "Basic base64(email:token)", Accept: "application/json"}`; base64 is UTF-8 safe. Throws if email or token is missing. The token is never logged and never appears in error messages.
- `Content-Type` and `X-Atlassian-Token` are added by jira-client on POSTs, not here.

## Acceptance
- `npm test` passes.
- The extension loads unpacked without manifest errors.
- Icons exist at all 12 paths and are valid PNGs of the right size.
